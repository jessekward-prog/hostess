🧙 hostess

One command turns a clean machine into a self-hosted app platform. Point selfhost-wizard at any repo with an app.yaml and it builds, deploys, and manages it in Docker for you.

Dashboard on localhost:5300, loopback only Source on GitHub ↗

Install

curl -fsSL https://raw.githubusercontent.com/jessekward-prog/selfhost-wizard/main/install.sh | bash

Prefer to read it first? view install.sh on GitHub before piping it to bash.

What it does / do it by hand
  1. Installs Docker, Node.js 18+, and git if any are missing (via apt and Docker's official install script). Adds your user to the docker group — you'll need to log out and back in (or run newgrp docker) before containers work. 
    sudo apt-get update -y && sudo apt-get install -y git
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker "$USER"
  2. Clones the repo and installs dependencies: 
    git clone --depth 1 https://github.com/jessekward-prog/selfhost-wizard.git ~/selfhost-wizard
cd ~/selfhost-wizard && npm install --omit=dev
  3. Registers a user-level systemd service so the dashboard survives reboot and logout: 
    mkdir -p ~/.config/systemd/user
cat > ~/.config/systemd/user/selfhost-wizard.service <<EOF
[Unit]
Description=Self-Host Wizard dashboard
After=network.target docker.service

[Service]
WorkingDirectory=%h/selfhost-wizard
ExecStart=$(command -v node) server.js
Restart=on-failure

[Install]
WantedBy=default.target
EOF
systemctl --user daemon-reload
systemctl --user enable --now selfhost-wizard
loginctl enable-linger "$USER"
  4. Open http://localhost:5300. Manage it any time with: 
    systemctl --user status  selfhost-wizard
systemctl --user restart selfhost-wizard
systemctl --user stop    selfhost-wizard

Tested against Debian/Ubuntu-family distros (apt). On another distro, install Docker/Node/git yourself first, then run steps 2–3.

curl -fsSL https://raw.githubusercontent.com/jessekward-prog/selfhost-wizard/main/install-macos.sh | bash

Prefer to read it first? view install-macos.sh on GitHub before piping it to bash.

What it does / do it by hand
  1. Installs Homebrew if missing, then git, node, and Docker Desktop: 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install git node
brew install --cask docker
  2. Launches Docker Desktop and waits for it to come up — the first run needs you to click through its permissions dialog: 
    open -a Docker
  3. Clones the repo and installs dependencies: 
    git clone --depth 1 https://github.com/jessekward-prog/selfhost-wizard.git ~/selfhost-wizard
cd ~/selfhost-wizard && npm install --omit=dev
  4. Registers a launchd agent so the dashboard survives logout and reboot: 
    cat > ~/Library/LaunchAgents/xyz.cmdward.selfhost-wizard.plist <<EOF
<?xml version="1.0" encoding="UTF-8"?>
<plist version="1.0"><dict>
  <key>Label</key><string>xyz.cmdward.selfhost-wizard</string>
  <key>ProgramArguments</key>
  <array><string>$(command -v node)</string><string>server.js</string></array>
  <key>WorkingDirectory</key><string>$HOME/selfhost-wizard</string>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
</dict></plist>
EOF
launchctl load -w ~/Library/LaunchAgents/xyz.cmdward.selfhost-wizard.plist
  5. Open http://localhost:5300. Manage it any time with: 
    launchctl unload ~/Library/LaunchAgents/xyz.cmdward.selfhost-wizard.plist
launchctl load -w ~/Library/LaunchAgents/xyz.cmdward.selfhost-wizard.plist

Works on both Apple Silicon and Intel Macs. Logs go to /tmp/selfhost-wizard.log.

Run this in PowerShell (Start → type "PowerShell"). It re-launches itself elevated — approve the UAC prompt. Prefer to read it first? view install.ps1 on GitHub.

What it does / do it by hand
  1. Installs git, Node.js LTS, and Docker Desktop via winget (built into Windows 10/11 — if missing, get "App Installer" from the Microsoft Store first): 
    winget install --id Git.Git -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Docker.DockerDesktop -e
  2. Enables the WSL2 backend Docker Desktop needs, if not already on: 
    wsl --install --no-distribution
    If this was just installed, Windows needs a reboot before Docker will start — the installer tells you this and stops cleanly; just re-run it after rebooting.
  3. Launches Docker Desktop and waits for it to be ready — first run needs you to click through its setup: 
    Start-Process "C:\Program Files\Docker\Docker\Docker Desktop.exe"
  4. Clones the repo and installs dependencies: 
    git clone --depth 1 https://github.com/jessekward-prog/selfhost-wizard.git $HOME\selfhost-wizard
cd $HOME\selfhost-wizard
npm install --omit=dev
  5. Registers a Scheduled Task (runs hidden, at logon, restarts on failure) so the dashboard survives reboot: 
    $action = New-ScheduledTaskAction -Execute "powershell.exe" `
  -Argument '-NoProfile -WindowStyle Hidden -Command "Set-Location $HOME\selfhost-wizard; node server.js"'
$trigger = New-ScheduledTaskTrigger -AtLogOn
Register-ScheduledTask -TaskName selfhost-wizard -Action $action -Trigger $trigger -Force
Start-ScheduledTask -TaskName selfhost-wizard
  6. Open http://localhost:5300. Manage it any time with: 
    Start-ScheduledTask -TaskName selfhost-wizard
Stop-ScheduledTask  -TaskName selfhost-wizard

Docker Desktop on Windows requires WSL2 — on a truly clean machine this means one reboot mid-install. That's Docker's requirement, not this script's.

Deploying an app

Once it's running, point selfhost-wizard at any repo with a Dockerfile and an app.yaml at its root:

name: my-app          # lowercase letters/numbers/hyphens, 2-50 chars
port: 3000             # port your app listens on *inside* the container
postgres: false        # true to get a DATABASE_URL wired to a shared Postgres
env: []                 # optional — extra env var names

Paste the repo URL (or a local path) into the dashboard, or from the CLI: node deploy.js <source>. Full manifest reference and dashboard walkthrough in the README.
